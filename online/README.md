# VoiceBench Online · 在线录音与收音分析

[English](README.en.md) · [第三方归属](THIRD_PARTY_NOTICES.md) · [ASR与时间对齐说明](ASR-NOTES.md)

`online-1.0.0` 是独立的 HTTPS 浏览器版本：同页录音、浏览器录音库、设备选择、语音转写、音质预测和报告导出都在当前浏览器中处理。使用者不需要安装 Python、FFmpeg、桌面程序或填写识别 API Key。

**在线入口：[打开 VoiceBench 在线版](https://voicebench-online.yujianxi0.chatgpt.site)**。站点已公开发布，并通过无账号登录的新浏览器环境完成转写、DNSMOS、响度、刷新恢复及报告下载验证。原本机 VoiceBench 项目独立保留，本项目不会修改其录音库或分析目录。

## 使用流程

1. 使用现代浏览器打开 HTTPS 页面。允许麦克风后，在“录音设备”中保留“浏览器默认”，或选择具体麦克风；插入新设备后点击“刷新设备”。选择会尝试连接新输入，请按“实际录音输入”核对音轨名称。
2. 开始录音，停止后等待浏览器录音库显示保存成功。当前录音或多选历史录音可在同页加入分析，无需先下载再手动导入；也可以导入已有音频文件。
3. 填写设备、场景和测试条件。原稿可选；需要内容识别评分时，添加正确原稿与关键词。不同原稿不合并计算字错率排名。
4. 首次分析会下载公开模型和运行时资源，并显示进度。等待浏览器完成转写、DNSMOS、音频指标和时间轴，再查看比较、回听及导出。
5. 支持独立 HTML、评分 CSV、定位 CSV 和完整 JSON。报告包含独立转写、原稿、疑点依据、定位限制和模型来源；HTML 不内嵌音频，可另行保留 WAV。

设备选择与本机版 1.3.1 保持相同操作方式：默认选项不强制设备 ID；明确选择麦克风时请求对应的精确 ID。设备选择仅保留在当前页，设备不可用或连接失败会报错，不静默切到另一台。连接、录音、停止保存时禁用设备切换；刷新设备列表不会替换录音库原件或未保存的 WAV。

录音模块最长 30 分钟；分析输入每份最多 10 分钟、100 MB，每批最多 20 份、500 MB。超限请先分段。输入上限不代表所有手机或电脑都能流畅处理长录音，建议先用 15～60 秒的小样确认浏览器表现。

## 与本机版的区别

| 项目 | 浏览器在线版 | 原本机版 |
| --- | --- | --- |
| 语音识别 | `Xenova/whisper-tiny`，多语种、q8量化、浏览器WASM | OpenAI Whisper small，本机Python/CPU |
| 分析执行 | 当前网页的浏览器及Worker | 本机后台服务 |
| 关闭或刷新页面 | 中断当前录音和未完成分析，不能继续后台运行 | 已提交给本机服务的分析可继续 |
| 用户数据 | 当前站点来源、浏览器配置中的本地存储 | 本机目录与原来源的浏览器录音库 |
| 解码 | 浏览器支持的格式与WebAudio能力 | FFmpeg支持的格式 |

**两个版本的ASR模型和解码设置不同，不可把识别字错率、内容分数或综合排名直接混合比较。** 浏览器tiny更小，不代表与small相同的识别准确性；干净录音中也可能识别出错。模型转写不能作为自己的正确原稿。

## 模型下载、缓存与运行

ASR固定为 `Xenova/whisper-tiny`，修订 `5332fcc35e32a33b86612b9a57a89be7906102b1`，通过 Transformers.js 3.8.1 和WASM在Worker内运行。量化权重约39 MiB，连同分词器、配置与ASR运行时，首次ASR资源约64 MiB；实际传输会受压缩、缓存和浏览器影响。DNSMOS和响度分析另有各自的模型或WASM资源。

资源随本站静态文件提供；ASR清单记录来源、大小和SHA-256，模型分片与合并结果在推理前检查。缓存可用时会复用已校验的公共模型；清理网站数据、缓存回收、换浏览器/配置文件或缓存空间不足时可能重新下载。缓存不能保证站点在完全离线或冷启动时始终可用。

录音以16 kHz单声道采样传入ASR，不发送给在线识别接口。首次下载较慢与正在转写是不同阶段；请结合进度查看。分析时保持页面开启。关闭、刷新或浏览器终止页面会中断当前任务，不会建立服务器后台队列；重新打开后只以浏览器已经成功保存的数据为准。

## 指标与定位边界

- CER按归一化后的字符计算，可以超过100%；内容保真分为 `max(0,100×(1−CER))`。没有正确原稿时，CER、内容分和关键词正确率保持未测，不补零。
- 音质按场景分组，重复录音按设备求均值与范围。CER另要求相同的非空归一化原稿。不同文案、条件不一致或样本不足时，不据此判定硬件优胜。
- DNSMOS P.835给出人声、背景、整体质量的模型预测，使用9.01秒窗口与1秒步长。短录音按上游方法重复补齐并标注；窗口分数不能因果分配给某一个字。
- 词或词组时间来自ASR实际对齐输出，不均分生成虚假的逐字时间。没有可靠词级时间时只保留可用片段时间；浏览器管线没有提供词置信概率时显示未测。
- 局部信号候选是待回听疑点，不等于收音故障；没有候选也不代表录音没有问题。原稿错误、口音、专有名词及模型能力也会影响识别。
- 响度与真峰值由浏览器中的 `ebur128-wasm` 计算；未获得可靠结果的项目保持未测。LRA目前未实现。频谱是文件频谱，不是校准后的麦克风频响；不凭录音文件生成真实声学SNR或人工可懂度。

WAV是主要验证的输入路径；其他格式取决于浏览器内置编解码器。WebAudio可能重采样、混合声道或限制格式支持，因此必须查看结果中的源采样率、分析采样率和声道说明，不能把浏览器解码输出冒充原始逐位采样。遇到不支持的格式或无有效采样时，请导出标准PCM WAV再重试。

## 数据、来源与保存

麦克风录音、导入文件、原稿和分析结果在当前浏览器中处理和保存；服务端提供页面及公开模型资源，不接收录音分析任务。导出文件可能包含私人转写内容，分享前应核对。

浏览器数据受**来源地址与配置文件**隔离：在线HTTPS站点、原本机 `127.0.0.1:8771`、旧分析 `8767`、其他域名、其他浏览器或配置文件都不会自动共用录音库。即使沿用录音库名 `vibe-personal-recordings`，也不会跨来源迁移数据。本机旧录音可在原地址导出WAV后，主动导入在线版；网页不能直接读取本机 `data/jobs/`。

清理网站数据、使用隐私模式、浏览器回收存储或重装可能使本地数据不可用。保存成功表示本次浏览器写入及校验完成，不是云端备份。重要录音和报告请另行导出保留。录音中或未保存的唯一副本存在时，保留离开保护提示；不要依靠关闭页面自动保存。

## 开发与验证

`dist/` 是可静态部署的页面、模块、公开模型和许可资源；`tests/` 为开发测试，不是用户录音库。开发服务需能提供ES模块、WASM与模型文件；真实部署使用HTTPS，不能直接双击HTML依靠 `file://` 使用麦克风与Worker。

```sh
node --test tests/*.mjs
node --check dist/reporting.mjs
```

报告测试覆盖场景/原稿分组、重复统计、缺测值、状态限制、SHA-256原稿标识、导出完整性和HTML/CSV注入防护。ASR的单独验证与资源清单见 [ASR-NOTES.md](ASR-NOTES.md)。浏览器功能和资源测试只证明对应路径；合成语音、模拟设备或开发机的计时不能替代真实硬件测试，也不承诺其他电脑、手机、长录音或公开托管后的固定性能。

## 本地开发与独立部署

在本目录运行 `python3 -m http.server 8080 --bind 127.0.0.1 --directory dist`，再打开 `http://127.0.0.1:8080`。正式发布时把整个 `dist/` 部署到支持 ES 模块、Worker 和 WASM 的静态 HTTPS 网站根目录，不需要构建、后端或 API Key。必须同时部署模型分块与许可证，不能只上传 HTML；单个资源均小于 25 MiB。

开发测试使用 Node.js 24 或更新版本，音频对照测试另需 FFmpeg；普通使用不需要安装这些工具。`node --test tests/*.mjs` 共有 30 项测试。公开源码不包含具体托管账号的站点配置、录音、测试录音或浏览器数据。
